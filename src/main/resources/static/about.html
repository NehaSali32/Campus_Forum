Campus Forum Platform

A secure digital communication, academic discussion, official notice dissemination, and resource sharing ecosystem engineered for modern higher education institutions.

Java 17 Spring Boot 3 MySQL 8.0 BCrypt Security Hibernate JPA Vanilla JavaScript (ES6+) Dual Light / Dark Theming Role-Based Access Control

Project Mission & Purpose

Conventional college communication relies on scattered notice boards, fragmented messaging groups, and ad-hoc emails. Campus Forum unifies institutional communication into a structured, verified, and accessible digital portal.

  • Verified Notices: Urgent, important, and departmental circulars with mandatory student acknowledgment tracking.
  • Academic Forum: Peer discussion boards with Verified Faculty answer badges.
  • Centralized Resources: Downloadable syllabi, previous exam papers, and laboratory manuals.
  • Document Locker: Private, secure student certificate and marksheet storage.

Engineering Architecture

Constructed following enterprise clean architecture patterns without bloated heavy frameworks:

Robust Backend: Spring Boot 3.2 Web MVC, Spring Data JPA with transactional relational constraints in MySQL.
Zero-Bloat Frontend: Pure semantic HTML5, CSS custom properties, and native asynchronous JavaScript Fetch API.
Security Foundation: Server-side HTTP session tracking with SHA-256 cryptographic salted hashing and strict role verification.
